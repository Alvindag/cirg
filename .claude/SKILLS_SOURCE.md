# Vendored Skills

The skills in `.claude/skills/` and workflow commands in `.claude/commands/`
are vendored from [jeffallan/claude-skills](https://github.com/jeffallan/claude-skills)
(v0.4.16, MIT licensed) so they are available as project-scoped skills in
this repository without requiring a separate plugin marketplace install.

To update, re-sync from the upstream repository and re-copy the `skills/`
and `commands/` directories.
