USB Drop Attacks
Physical security meets cyber threat — how a USB drive in the car park can compromise the entire DAS Plc network.

💾 What Is a USB Drop Attack?

A USB drop attack is when an attacker deliberately leaves a malicious USB flash drive where a target employee will find it — in a car park, reception desk, toilet, or canteen. The drive executes malware automatically the moment it is plugged in. Within seconds the attacker can have:

  • Full remote access to your workstation and all connected network drives
  • Keyloggers recording every password you type — including Business Central and M365
  • Ransomware spreading to the entire DAS Plc file server
  • Access to DASDC01 (Domain Controller), Business Central, and Active Directory

⚠️ DAS Plc Audit Finding NC-2026-0004: USB ports are currently unrestricted on DAS Plc workstations. The IT team is deploying Group Policy to restrict USB access. Until then, YOUR AWARENESS is the primary control.

📋 DAS Plc USB Security Policy

  • Never plug in any USB device not issued by IT or approved by your department
  • If you find an unknown USB on DAS Plc premises, hand it to IT (Ext. 204) immediately
  • Personal USB drives from home are NOT permitted on DAS Plc workstations
  • Preferred file transfer method: SharePoint or \\DASDC01\shared network drive

🔒 Upcoming: USB GPO Restriction

IT is deploying a Group Policy Object (GPO) that will block all unauthorised USB devices across all 200+ DAS Plc workstations. Only IT-approved devices will be whitelisted. This directly addresses Audit Finding NC-2026-0004.

Until the GPO is live, your awareness is the primary defence. If you receive a USB from anyone — even a colleague — verify with IT (Ext. 204) before plugging it in.
