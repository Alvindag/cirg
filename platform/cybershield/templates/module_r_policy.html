Policy Updates 2026
What has changed in DAS Plc IT Security Policy since your last training. Three key updates every employee must know — and act on.

🔒 Update 1: USB Port Restriction GPO (NC-2026-0004)

Following Audit Finding NC-2026-0004, a Group Policy Object (GPO) has been deployed across all DAS Plc workstations to block unauthorised USB devices at the operating system level.

  • Personal USB drives are now blocked at the OS level on all 200+ workstations
  • Only IT-approved, whitelisted USB devices will work
  • Covers all DAS Plc workstations
  • Violation by attempting to circumvent the GPO is a disciplinary matter
💡 If you have a legitimate business need to use a specific USB device, submit a formal request to IT (Ext. 204 or IThelpdesk@dasplcgh.com) with your line manager's written approval. Exceptions require documented justification and are logged in the ISMS system.
📁 Approved file transfer alternatives:
  • DAS Plc SharePoint (Microsoft 365)
  • OneDrive for Business
  • Internal network share: \\DASDC01\shared
  • Business Central document attachments (for ERP-related files)

🔐 Update 2: MFA Mandatory for All M365 Accounts (R-2026-0001)

Following Risk Register item R-2026-0001 (No MFA — Critical Risk Score: 25), Multi-Factor Authentication is now mandatory for all Microsoft 365 accounts at DAS Plc.

  • All staff must enrol in MFA using the Microsoft Authenticator app on their mobile phone
  • Setup takes approximately 5 minutes — IT sent setup instructions by email
  • M365 access will be blocked for accounts not enrolled after the compliance deadline
  • Covers: Outlook, Teams, SharePoint, OneDrive, Business Central — all M365 services
  • If you have not yet enrolled, contact IT immediately on Ext. 204
🚨 CRITICAL: Unexpected MFA Push = Live Attack
If you receive an MFA approval request that YOU did not initiate — DENY IT immediately, then change your password and call IT on Ext. 204.
This means someone has your password right now and is attempting to log into your account.

📢 Update 3: Incident Reporting Timeline

DAS Plc IT Security Policy has been updated to align with NIST SP 800-61 and Ghana Cybersecurity Authority guidelines. New reporting requirements effective immediately:

Incident TypeReport WithinContact
All suspected security incidents 24 hours Assistant IT Manager — Ext. 204
Active attack / ransomware in progress IMMEDIATELY IT + Line Manager + MD
Data breach / personal data exposure IMMEDIATELY IT + Ghana DPA Data Controller
Lost or stolen device (laptop, phone, USB) Within 1 hour Assistant IT Manager — Ext. 204
Suspicious email, call, or visitor Same day Assistant IT Manager — Ext. 204
Accidental click on phishing link IMMEDIATELY — do NOT wait IT — Ext. 204 — disconnect network first

⚠️ All incidents are formally documented using CIRG (Cyber Incident Report Generator) and digital evidence stored in CFEMS. Do not delete any logs, emails, or files related to a suspected incident before IT has reviewed them — this preserves the forensic chain of evidence.
