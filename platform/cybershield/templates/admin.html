💾 Backup & Recovery

ISO 27001:2022 A.8.13

All training completions, scores, and certificate references are stored in instance/cybershield.db. Exports produce a structured JSON file containing every trainee record, quiz score, and custom question. Server-side copies are retained automatically for up to 30 versions in instance/backups/. Compliant with ISO 27001:2022 A.8.13 and DAS IT Policy IT22-001. Recommended: back up weekly or before any system changes.

📤 Export Full Backup

Downloads a complete JSON backup of all trainee records, certificates, quiz scores, and custom questions. A timestamped copy is also saved automatically server-side.

Each time you click Download Backup, a copy is also saved on the server. The last 30 are retained. You can download any version to restore a previous state — important if a system failure or accidental deletion occurs.
