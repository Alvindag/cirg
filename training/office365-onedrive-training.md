# Microsoft 365 OneDrive Training — "Beat the Clock: Closing Out Your Day"

## Training Concept

Every employee has one recurring, high-stakes moment each day: **the final push before close of business (COB)** — saving the report, sharing the deliverable, handing off to the next shift, or making sure nothing is lost overnight. This training uses that daily moment as the anchor scenario for learning OneDrive, moving employees from Beginner → Intermediate → Advanced entirely through realistic, task-based situations rather than abstract feature tours.

**Format:** Each level contains scenario-based modules. Each scenario follows: *Situation → Why it matters → Step-by-step → Pro tip*.

---

## Brainstormed Daily "Before COB" Scenarios (pool used to build the curriculum)

1. Saving the day's final report so it's never lost if the laptop fails overnight
2. Emailing a file to a manager vs. sending a link
3. Recovering a file accidentally deleted at 4:55 PM
4. Handing off an in-progress file to a colleague or the next shift
5. Restoring yesterday's version because today's edits broke a file
6. Freeing up laptop storage while keeping access to all files (Files On-Demand)
7. Finishing a report on a phone during a commute after leaving the office
8. Sharing a sensitive financial/HR file with an expiring, view-only link
9. Consolidating multiple people's daily trackers into one file before a deadline
10. Working offline on a spotty connection while traveling, then syncing before a deadline in another time zone
11. Checking who has accessed or edited a confidential file (audit trail)
12. Setting up automatic backup of the Desktop/Documents folders so nothing is ever manually "saved before leaving" again

These scenarios map directly to the modules below.

## LEVEL 1 — BEGINNER: "Never Lose a Day's Work"

### Module 1.1 — Save It Once, Never Lose It
**Situation:** It's 4:45 PM. You just finished today's status report in Word/Excel and want it safe even if your laptop won't turn on tomorrow.
**Why it matters:** Files saved only to the local Desktop or "This PC" exist on one machine. If that machine is lost, stolen, or crashes, the day's work is gone.
**Steps:**
1. Click **File → Save As** (or `Ctrl+S` on a new file).
2. Choose **OneDrive – [Your Company]** as the save location.
3. Confirm the small blue OneDrive cloud icon appears next to the filename in File Explorer.
4. Watch the sync icon on the taskbar: a spinning circle means it's uploading; a green checkmark means it's safely backed up.
**Pro tip:** Before you shut your laptop, glance at the OneDrive icon in the system tray — a green check means it's genuinely safe to walk away.

### Module 1.2 — Send a Link, Not an Attachment
**Situation:** Your manager emails at 5:00 PM asking for the file you just finished.
**Why it matters:** Emailed attachments create multiple outdated copies floating around. A link always points to the current version.
**Steps:**
1. Right-click the file in OneDrive (or File Explorer) → **Share**.
2. Choose **People in [Company] with the link** (or the correct audience).
3. Set permission to **Can view** or **Can edit** as appropriate.
4. Click **Copy link**, paste it into your email or Teams chat, and send.
**Pro tip:** If you attach the file out of habit, Outlook will prompt "Share a link instead?" — always say yes.

### Module 1.3 — The 5:01 PM Panic: Recovering a Deleted File
**Situation:** You just deleted the file you need, one minute after closing your laptop lid mentally for the day.
**Why it matters:** Panic leads to mistakes; knowing the recovery path removes the stress.
**Steps:**
1. Go to **OneDrive.com** and sign in.
2. Click **Recycle bin** in the left menu.
3. Find the file, select it, and click **Restore**.
**Pro tip:** Files stay in the OneDrive recycle bin for up to 30 days — you almost never truly lose something.

## LEVEL 2 — INTERMEDIATE: "Hand Off and Recover Like a Pro"

### Module 2.1 — Handing Off Work to the Next Shift or a Colleague
**Situation:** You're leaving at 5 PM but a teammate on a later shift (or in another time zone) needs to keep working on the same tracker tonight.
**Why it matters:** Without co-authoring, people overwrite each other's edits or create "final_v2_reallyfinal" chaos.
**Steps:**
1. Share the file with **Can edit** permission (Module 1.2 steps).
2. Open the file yourself first to confirm it's the correct, current version.
3. In Word/Excel/PowerPoint, check the top-right corner — you'll see your colleague's name appear once they open it too (real-time co-authoring).
4. Leave a note for them using **@mention** in a comment (Review tab → New Comment → type `@` + their name) instead of a separate email.
**Pro tip:** @mentioning someone in a comment automatically emails them a link — a faster handoff than writing a new message.

### Module 2.2 — "Today's Edits Broke It": Restoring a Previous Version
**Situation:** At 5:15 PM you realize this afternoon's edits corrupted a formula or deleted a section, and you need this morning's version back.
**Why it matters:** OneDrive automatically keeps prior versions — you don't need to have manually saved backup copies.
**Steps:**
1. Right-click the file in OneDrive → **Version history**.
2. Browse the list of timestamped versions saved throughout the day.
3. Click **Restore** on the version you need (or **Open/Download** to compare first).
**Pro tip:** Do this before recreating work from memory — it's almost always faster than redoing it.

### Module 2.3 — Free Up Laptop Space Without Losing Access
**Situation:** Your laptop warns "low disk space" right as you're trying to save today's final files.
**Why it matters:** Files On-Demand keeps every file visible and clickable in File Explorer without permanently storing it on your hard drive.
**Steps:**
1. Right-click the OneDrive icon in the system tray → **Settings → Sync and backup → Advanced settings**.
2. Enable **Files On-Demand** (usually on by default).
3. In File Explorer, right-click any folder you use daily → **Always keep on this device** (for files you need offline), or **Free up space** for files you rarely touch.
**Pro tip:** Icons tell the story: a cloud icon = online-only, a green check = downloaded and available offline.

### Module 2.4 — Finishing Work From Your Phone After Leaving
**Situation:** You left the office, but remember on your commute that the report is due by 6 PM.
**Why it matters:** OneDrive mobile lets you complete the "before COB" task from anywhere.
**Steps:**
1. Open the **OneDrive** app (or Word/Excel app) on your phone, signed in with your work account.
2. Tap **Recent** to find the file you were just working on.
3. Edit directly — changes sync automatically the moment you have signal.
4. Use the **Share** icon in the mobile app to send the link the moment it's done.
**Pro tip:** Turn on notifications for comments/@mentions so you know immediately if someone responds after hours.

## LEVEL 3 — ADVANCED: "Protect, Consolidate, and Prove It"

### Module 3.1 — Sharing Sensitive Data Safely Before a Deadline
**Situation:** You must send a month-end file with salary or customer data to an external auditor by COB, but it must not be forwardable or accessible after the deadline.
**Why it matters:** Standard links can be forwarded indefinitely; sensitive data needs controlled, time-boxed access.
**Steps:**
1. Right-click the file → **Share**.
2. Click the settings gear next to the link type and choose **Specific people**.
3. Enter the auditor's exact email address.
4. Toggle **Set expiration date** and choose the day after the deadline.
5. Disable **Allow editing** and toggle off **Allow download** if it should be view-only.
6. If your organization uses sensitivity labels, apply the appropriate label (e.g., **Confidential – Finance**) from the **Sensitivity** button in Word/Excel before sharing.
**Pro tip:** Expiring, named-recipient links satisfy most compliance and audit requirements automatically — no manual follow-up "please delete this file" email needed.

### Module 3.2 — Consolidating Everyone's Daily Trackers Into One File
**Situation:** Five team members each keep a personal daily task tracker, and you must merge them into one department summary before COB.
**Why it matters:** Manual copy-pasting is slow and error-prone; co-authoring and linked data eliminate the bottleneck.
**Steps:**
1. Create one master Excel workbook in a shared OneDrive/Team folder with a tab per team member (or use Excel's **Data → Get Data → From File** to pull ranges from each person's file).
2. Share the master file with **Can edit** access to the team.
3. Ask each person to update their own tab simultaneously — co-authoring shows live cursors and prevents overwrites.
4. Use **Excel Tables** and simple `SUM`/`XLOOKUP` formulas referencing each tab to auto-build the summary view.
**Pro tip:** Once set up, this "merge" becomes a one-time click each day instead of a recurring 30-minute manual task.

### Module 3.3 — Working Offline Across Time Zones, Then Syncing to Meet a Deadline
**Situation:** You're traveling with unreliable Wi-Fi, and your COB deadline is actually mid-morning your time because it's tied to a different region's business hours.
**Why it matters:** Offline-first editing plus reliable sync means connectivity gaps don't cause missed deadlines.
**Steps:**
1. Before traveling, mark key folders **Always keep on this device** (Module 2.3) so they're fully available offline.
2. Edit normally while offline — OneDrive queues the changes locally.
3. Once connectivity returns, check the OneDrive taskbar icon for the sync spinner; wait for the green check before considering the file "sent."
4. For a hard deadline, confirm sync completion on **OneDrive.com** in a browser (shows the true server-side timestamp) rather than trusting the local clock alone.
**Pro tip:** Convert the recipient's deadline into your own local time zone in your calendar so "before COB" always means the correct moment for the audience, not for you.

### Module 3.4 — Proving Who Accessed a Confidential File (Audit Trail)
**Situation:** Compliance asks you to confirm who viewed or edited a confidential file this week before it's archived at end of day.
**Why it matters:** Regulated industries (finance, healthcare, government) require demonstrable access control, not just access control itself.
**Steps:**
1. Open the file in OneDrive/SharePoint, click the **Info** panel (or **i** icon).
2. Review **Activity** to see who viewed, edited, or shared the file and when.
3. For a full access log, click **Manage access** to see everyone with permissions and remove anyone who no longer needs it.
4. For formal audit exports, escalate to IT/Security, who can pull detailed logs from the **Microsoft Purview compliance portal**.
**Pro tip:** Reviewing "Manage access" weekly on sensitive files is a five-minute habit that prevents most accidental over-sharing incidents.

### Module 3.5 — Set-and-Forget Backup So "Saving Before Leaving" Is Never Manual Again
**Situation:** You want to stop relying on remembering to save to OneDrive every single day.
**Why it matters:** Automating the backup removes human error from the entire training's core problem.
**Steps:**
1. Open OneDrive **Settings → Sync and backup → Manage backup**.
2. Toggle on backup for **Desktop**, **Documents**, and **Pictures**.
3. Confirm existing files begin syncing (progress shown in the same panel).
4. Going forward, anything saved to those folders — by habit, by default — is automatically protected, with no extra "before COB" step required.
**Pro tip:** This module is the natural graduation point: once set up, Module 1.1 becomes automatic for every employee on the team.

## Suggested Delivery Plan

| Session | Levels Covered | Duration | Format |
|---|---|---|---|
| Session 1 | Level 1 (all modules) | 30 min | Live demo + hands-on practice with a sample file |
| Session 2 | Level 2 (all modules) | 45 min | Paired exercise: one "handoff," one "recover a version" |

## Quick Reference: Skill Checklist by Level

- **Beginner:** Save to OneDrive, share via link, restore from Recycle Bin
- **Intermediate:** Co-author with a colleague, use @mentions, restore version history, Files On-Demand, mobile app
- **Advanced:** Expiring/restricted sharing + sensitivity labels, multi-user consolidation, offline sync across time zones, access audit trail, automatic Desktop/Documents backup
